# EduSphere 🎓🚀

> **The AI-Driven University Life Operating System**  
> *Transforming raw academic degrees into actionable, 4-year career execution roadmaps and adaptive daily learning workflows.*

---

## 🌟 Overview

University degrees provide the theory, but students often struggle to connect coursework to industry-ready careers. **EduSphere** bridges this gap. 

By leveraging AI, EduSphere ingests university syllabi and lecture slides, breaking them down into structured skill trees, dynamic 4-year career execution roadmaps, and self-assessment quizzes. It empowers students to navigate their academic journey with clear career milestones, real-time skill tracking, and personalized daily study plans.

---

## ✨ Key Features

* **📄 Lecture & Syllabus Parsing:** Upload course materials (PDFs, slides) and automatically extract key concepts, technical competencies, and learning outcomes.
* **🗺️ Dynamic 4-Year Roadmaps:** Convert degree requirements into visual, step-by-step career execution paths tailored to your target industry.
* **🌳 Skill Tree Visualization:** Track your progress through interactive skill nodes as you complete coursework and personal projects.
* **🧠 Adaptive Quiz Generation:** Generate custom practice quizzes directly from your class slides to prepare for exams and technical interviews.
* **🎯 Specialization Matching:** Discover specialized career tracks based on your strengths, academic performance, and personal interests.

---

## 🛠️ Tech Stack

* **Frontend:** React / Next.js, Tailwind CSS
* **Backend:** Node.js / Python (FastAPI)
* **AI & LLM Orchestration:** OpenAI API / Anthropic Claude API / LangChain
* **Database:** PostgreSQL / Supabase
* **Deployment:** Vercel
